>**IDEdu**는 **온라인 코딩 교육의 한계점을 극복하기 위한 클라우드 코딩 플랫폼**입니다.   
>교육 중 교수자와 학생의 IDE 상태는 실시간으로 중계되어 서로의 코드를 확인할 수 있으며, 
>교수자는 학생의 코드를 수정할 수 있습니다.   
>서버는 모든 학생의 빌드 기록을 저장하며, 각 학생이 어느 부분에서 실수를 하는지 파악할 수 있습니다.
